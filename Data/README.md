# Data Attribution and Usage Notice

This folder contains sample coordinate data used for testing and evaluating the geometric fitting algorithms
in the **OpenDiMet** project.

## Important Notes:

The original reference datasets were obtained from the **National Institute of Standards and Technology (NIST)**.
NIST provides data to support research, reproducibility, and benchmarking activities in science and engineering.

Source: https://www.nist.gov/pml/sensor-science/dimensional-metrology/algorithm-testing

- NIST is **not affiliated with, does not endorse, and has not validated** this software or repository.
- Data in this folder may have been renamed, reformatted, or reorganized for demonstration purposes.
- Refer to official NIST website for documentation and further details.
